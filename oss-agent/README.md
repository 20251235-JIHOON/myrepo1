# oss-agent

영화진흥위원회 [KOBIS 오픈 API](https://www.kobis.or.kr/kobisopenapi/homepg/main/main.do)로 일별 박스오피스를 조회하는 파이썬 실습 저장소입니다.

## 구성

```
oss-agent/
├── .gitignore
├── week09/
│   └── 영화 관객 수 조회 실습
└── week10/
    ├── compared.txt       # 비교 기록
    ├── notes_after.md     # 작업 후 노트
    ├── notes_before.md    # 작업 전 노트
    ├── notes_before2.md   # 작업 전 노트 추가본
    └── oss_tlftmq.txt     # 실습 파일
```

## week09

`week09`에는 KOBIS 일별 박스오피스 API로 지정한 날짜의 영화 관객 수를 조회하는 실습이 있습니다. API 키는 `KOBIS_API_KEY` 환경변수로 설정합니다. 자세한 실행 방법은 각 실습 파일을 확인하세요.

## week10

`week10` 폴더에는 비교 기록과 작업 전후 노트, 실습 텍스트 파일이 포함되어 있습니다.
