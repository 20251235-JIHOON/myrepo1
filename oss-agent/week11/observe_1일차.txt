[1일차]

1. (6단계) 빈칸을 채우지 않고 실행했을 때, call 안에 보인 도구 이름과 인자는?
답: 도구 이름 get_boxoffice_rank_1, 인자 "{\"date\":\"20261108\"}" (글자로 된 JSON)

2. (8단계) 빈칸 1을 채우고 실행했을 때, 화면 마지막 줄은?
답: FUNCTIONS 사전에서 'get_boxoffice_rank_1' 함수를 꺼내 func 에 담을 것.

3. (선택) 2위 영화를 물었을 때, 모델은 어떤 도구를 불렀나? 부르지 않았다면 뭐라고 답했나?
답: 2위를 알려주는 도구가 없는데도 get_boxoffice_rank_1 을 {'date': '20261108'} 로 불렀다. 모델은 도구 이름과 설명만 보고 가장 가까운 도구를 고른 것 같다.


[추가 진행 — 빈칸 2, 3 채우기]

4. 빈칸 2를 채우고 실행했을 때, "도구 결과:" 줄에 나온 것은?
답: 도구 결과: 극장판 치이카와: 인어 섬의 비밀
   (채운 코드: func = FUNCTIONS[name])

5. 빈칸 3을 채우고 실행했을 때, 몇 바퀴 만에 끝났나?
답: 3바퀴
   (채운 코드: tool_message = {"role": "tool", "tool_call_id": call["id"], "name": name, "content": str(result)})

6. 바퀴마다 찍힌 대화 길이는?
답: 1바퀴 2, 2바퀴 4, 3바퀴 6 (바퀴마다 모델 답 + 도구 결과로 2씩 늘어남)

7. 모델이 부른 도구의 순서는?
답: get_boxoffice_rank_1 {'date': '20261108'} → get_movie_audience {'date': '20261108', 'title': '극장판 치이카와: 인어 섬의 비밀'} (결과 62,973명)
   최종 답: 1위 영화는 '극장판 치이카와: 인어 섬의 비밀', 관객 수 62,973명

8. 도구가 필요 없는 질문("파이썬은 누가 만들었어?")은 몇 바퀴 만에 끝났나? 도구를 불렀나?
답: 1바퀴 만에 끝남. 도구를 부르지 않고 바로 "귀도 반 로섬이 만들었습니다"라고 답함.

9. 미래 날짜(2026년 12월 25일)를 물었을 때, 도구 결과와 최종 답은?
답: 도구 결과 "20261225 에는 집계된 자료가 없습니다." / 최종 답 "2026년 12월 25일은 아직 오지 않은 날짜여서 집계된 박스오피스 자료가 없습니다."

10. MAX_TURNS 를 2로 줄였을 때, 화면 마지막 줄은?
답: 최종 답: 2바퀴를 돌아도 끝나지 않아 멈춤.

11. 한 줄 정리 — Claude Code 를 쓸 때 화면에서 본 것 중, 오늘 코드에서 찾은 것은?
답: Claude Code 화면에 뜨는 도구 호출(Read, PowerShell 등)과 그 결과가 이어지는 모습이 loop.py 의 "도구 호출: / 도구 결과:" 줄과 같다. 모델은 부르겠다고만 하고, 하네스가 실행하고 결과를 대화에 다시 넣는 반복이다.
