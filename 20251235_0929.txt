2. 동일한 파일의 같은 줄을 서로 다르게 했으므로 Git이 어느 내용을 선택해야할지 알수없어 출돌이 발생한다 (O)

3. 서로 다른 파일을 수정했기 때문에 각각의 변경 사항이 그대로 반영되오 충돌이 발생하지 않습니다 (X)

4. 한쪽은 파일 내용을 수정하고 다른쪽은 해당파일을 삭제한경우 병합하지 못해 충돌이 발생한다 (O)

5. 민수의 작업이 먼저 메인 브랜치에 병합된 이후 지연이가 최신 상태를 기반으로 작업 및 병합을 진행하는 흐름이므로 충돌이 발생하지 않는다 (X)

- ( ) main에서 바로 파일을 고치고 커밋한다

- ( 2 ) 원본을 건드리지 않도록 브랜치를 갈라낸다
- ( 4 ) 합쳐 달라고 요청을 만든다
